# Proposition Design & Architecture — QDIA Export (style Alibaba)

Voici une proposition structurée **avant toute modification de code**, basée sur votre base actuelle (Laravel 10 + Flutter Web + module IA + cotations Incoterms).

---

## 1. Vision produit

**QDIA Export** = marketplace B2B international pour produits algériens (alimentation, cosmétique, artisanat, industrie légère), inspirée d’**Alibaba** :

| Acteur | Rôle |
|--------|------|
| **Producteur algérien** | Publie ses produits, photos, MOQ, certifications |
| **Acheteur étranger** | Cherche, compare, demande devis (RFQ), négocie |
| **Agent IA QDIA** | Remplit la fiche, génère/édite images, calcule prix export, publie sur la plateforme |
| **Admin QDIA** | Valide vendeurs, modère catalogue, supervise cotations |

**Pivot par rapport au B2B actuel** : vous gardez le moteur multi-vendeurs (`Vendor` → `Store` → `Item`), mais vous ajoutez une **couche export** visible internationalement, avec pricing Incoterms et un agent IA orienté publication.

## 4. Agent IA QDIA — architecture

L’agent n’est pas un simple chatbot : c’est un **orchestrateur de tâches** avec plusieurs compétences.

```mermaid
sequenceDiagram
    participant P as Producteur
    participant UI as App Producteur
    participant AG as Agent Orchestrateur
    participant CAT as Catalogue Service
    participant IMG as Image Service
    participant PRC as Pricing Engine
    participant DB as Base de données

    P->>UI: Photo + "Huile olive Béjaïa 1L"
    UI->>AG: POST /ai/agent/publish-product
    AG->>IMG: Détourage + fond blanc + watermark
    IMG-->>AG: 3 images optimisées
    AG->>AG: GPT-4o Vision → fiche produit FR/EN/AR
    AG->>PRC: Calcul EXW/FOB/CFR/CIF
    PRC-->>AG: Prix par Incoterm + marchés
    AG->>CAT: Créer Item (status: pending_review)
    AG-->>UI: Fiche complète + prix + images
    P->>UI: Confirmer publication
    UI->>DB: Item approuvé → visible export
```

### Compétences de l’agent (modules)

| Compétence | Entrée | Sortie | Techno |
|------------|--------|--------|--------|
| **ProductWriter** | Photo/texte | Titre, description SEO, catégorie, specs | GPT-4o (existant) |
| **ImageEnhancer** | Photo brute | Packshot pro, fond blanc | DALL-E / Stable Diffusion + remove.bg |
| **ExportPricer** | Coût unitaire, qty, destination | EXW/FOB/CFR/CIF + marge | `ExportQuotation::calculate()` + IA marché |
| **ComplianceChecker** | Produit + destination | Alertes (halal, phytosanitaire, embargo) | Règles + GPT |
| **Publisher** | Fiche validée | `Item` publié module ecommerce export | Laravel |

### Nouveau module Laravel suggéré : `Modules/ExportAI/`

```

├── Services/
│   ├── AgentOrchestrator.php      # Coordonne le pipeline
│   ├── ProductWriterService.php   # Étend ProductAutoFillService
```

Vous avez déjà la base dans `ExportQuotation` :

```43:71:c:\Users\Roqia\Downloads\public_html(2)\admin\app\Models\ExportQuotation.php
    public static function calculate(array $d): array
    {
        // EXW → FOB → CFR → CIF
        // + marge + frais QDIA
```

**Extension proposée**

```
Prix final = ExportQuotation::calculate()
           + suggestion IA (benchmark marché destination)
           + ajustement saisonnier
           + taux de change (DZD → USD/EUR)
```

| Niveau de prix affiché | Usage |
|------------------------|-------|
| **Prix indicatif FOB** | Visible sur la fiche (comme Alibaba) |
| **Prix exact** | Après RFQ avec quantité et destination réelles |
| **Fourchette** | Si données incomplètes (ex. "3,80 – 4,50 USD/kg") |

L’IA enrichit les inputs (fret estimé, frais port Alger/Oran/Annaba) ; le calcul reste **déterministe** pour la traçabilité commerciale.

## 9. Phases de déploiement suggérées

### Phase 1 — Fondations (4–6 semaines)
- Module `export` : routes manquantes, `export_product_profiles`
- Portail acheteur MVP (catalogue + fiches produit)
- Extension agent IA : fiche produit + pricing FOB basique
- Compléter persistance import producteurs (aujourd’hui en session)

### Phase 2 — Studio & Agent complet (4–6 semaines)
- Studio images (détourage, watermark, génération IA)
- Pipeline agent : photo → fiche → prix → publication
- RFQ acheteur + lien avec `ExportQuotation`
- KYC producteurs

### Phase 3 — Marketplace mature (6–8 semaines)
- Recherche avancée, filtres pays/Incoterm
- Messagerie B2B, négociation devis
- Paiements internationaux (acompte, escrow optionnel)
- Analytics admin, API fret (optionnel)

### Phase 4 — Scale
- Apps mobiles producteur/acheteur
- Multi-devises, multi-langues étendu
- Intégration douanes / documents export

## 10. Points d’attention

| Sujet | Recommandation |
|-------|----------------|
| **Séparation B2C local / Export** | Nouveau module `export` ou flag `is_export` sur `Item` |
| **Flutter actuel** | Garder pour livraison locale ; nouveau front export séparé |
| **Coûts IA** | Quotas par vendeur (déjà `image_wise_ai_use_count`) |
| **Conformité** | Validation humaine avant publication (admin) |
| **SEO international** | Portail Next.js avec URLs `/en/products/olive-oil-algeria` |
| **Sécurité** | KYC producteurs, modération images IA |
